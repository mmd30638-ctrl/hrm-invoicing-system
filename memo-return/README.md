# মেমো ফেরত

বিক্রয় মেমো নম্বর দিয়ে পণ্য ফেরত নেয়। রেজিস্টার্ড কাস্টমারের সাবেক টাকা থেকে ফেরতের নীট টাকা মাইনাস হয়, স্টক ফিরে আসে, এবং বিক্রয় মেমোর মতো একটি ফেরত মেমো তৈরি হয়। সেই মেমো প্রিন্ট, হোয়াটসঅ্যাপ, ফেসবুক, এসএমএস, লিংক কপি ও ফোনের শেয়ার দিয়ে পাঠানো যায়।

একই ফোল্ডার টেস্টিং সাইট ও লাইভ সাইটে চলে। প্রতিটি সাইটে আলাদা `config.local.php` থাকবে।

## বসানো

জিপের নাম `Aponshop_10.98.798_FULL.zip`। আগের আপডেটের মতো ছোট ফুল প্যাকেজ। ভিতরে `public_html/memo-return/` আছে। আরেকটি জিপ নেই। `/get/` চাপলেই এই ফাইল নামতে শুরু করে।

এই প্যাচ `.env`, `uploads` ছবি, এবং `SPEED.txt` রাখে না ও মুছে না। সেটিংস → স্পিড সিস্টেম আগের ফাইলই থাকবে।

1. ইঞ্জিন রুমে নিচের সরাসরি ফাইল লিংক দিয়ে «সার্ভার নামান» চাপুন। লিংকটি এইচটিএমএল পাতা নয়, জিপ ফাইল।
2. `config.example.php` কপি করে `config.local.php` করুন।
3. সেই সাইটের ডাটাবেস নাম, ইউজার ও পাসওয়ার্ড দিন। `gate_password`-এ একটি লম্বা পাসওয়ার্ড দিন।
4. শেয়ার লিংক ঠিক রাখতে `public_url` দিন। উদাহরণ: `https://coral-crow-254990.hostingersite.com/memo-return/public`
5. ব্রাউজারে `/memo-return/public/` খুলুন।

দোকানের লগইন সেশন (`APONSHOP_STG`) থাকলে আলাদা পাসওয়ার্ড ছাড়াই ঢোকা যায়, যদি সেশনে ইউজার থাকে।

## হিসাব

রেজিস্টার্ড কাস্টমারের মেমোতে:

- সাবেক টাকা = ফেরতের আগের বকেয়া
- বর্তমান ফেরত = এই মেমোর নীট ফেরত
- টোটাল = সাবেক − ফেরত

খুচরা মেমোতে কাস্টমারের বকেয়া বদলায় না, শুধু স্টক ফেরে। একই ফেরত দুবার সেভ হলে টাকা দ্বিতীয়বার কাটে না। ড্রাফট মেমো থেকে ফেরত হয় না।
